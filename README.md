# GameXD · Weapon & Item Icons

Библиотека пиксельных иконок и соответствий **Megabonk → наши ассеты**: 30 оружий и 85 предметов. Основной набор и ранние глянцевые варианты хранятся отдельно.

## Начать просмотр

Клонируйте репозиторий или скачайте его ZIP и распакуйте целиком. Откройте **[assets/review/index.html](assets/review/index.html)** обычным браузером. Сервер и установка зависимостей для просмотра не нужны. Если смотрите этот README на GitHub, сначала скачайте файлы: GitHub показывает исходник HTML.

| Набор | Статус | Иконки | Предпросмотр |
| --- | --- | ---: | --- |
| `weapons-current` | Основной — актуальный | 30 | [Пушки](assets/review/weapons/preview.html) |
| `items-current` | Основной — актуальный | 85 | [Айтемы](assets/review/items/preview.html) |
| `items-glossy-early` | **Глянец — ранняя версия, архив** | 85 | [Глянцевые айтемы](assets/review/items-glossy-early/preview.html) |

Это **115 игровых сущностей и 200 вариантов PNG**. Архив не добавляет новые предметы. Не смешивайте ранний глянец с основным набором автоматически; выбирайте версию явно. Основной набор включает последние матовые правки и ранее сохранённые рисунки.

## Для балансировки и работы с ИИ

Начните с **[инструкции для ИИ](assets/review/AI_USAGE.md)** и **[поиска по оригинальным названиям](assets/review/lookup.json)**. Затем используйте [общий каталог](assets/review/manifest.json). Для каждого оружия и айтема сохранены оригинальное имя Megabonk, наши названия EN/RU, источник, описание оригинального эффекта, постоянный ключ и пути к PNG.

Например: **Anvil → Triune Gear / Тройная шестерня → `items/ours/01.png`** внутри `assets/review/`. Запись `item_01` имеет две явные версии: `item_01@current` и `item_01@glossy-early`. По умолчанию выбирается актуальная. У ранних вариантов могут быть исторические имена; соответствующая карточка указывает актуальное имя той же сущности.

`original_key` связывает сущность с Megabonk; `asset_id` различает наши предметы и оружие; `set_id` и `variant_id` задают конкретную версию изображения. Числовые ID каталога не являются внутренними enum Megabonk.

Описания эффектов служат сопоставлению. Числовой баланс и игровая реализация ведутся отдельно. Для спорных описаний источников есть примечания в данных и карточках.

## Структура

- `assets/review/` — самостоятельный переносимый пакет: HTML, все выбранные PNG, JSON/CSV, карточки и листы сравнения. Всю папку нужно сохранять вместе.
- `assets/weapon-icons/` — рабочие оружейные ассеты и скачанные оригинальные референсы.
- `assets/items/` — оригиналы, рабочие версии, промпты и сохранённые этапы обработки.
- `tools/build_asset_review.py` — сборка пакета и проверка ссылок, хешей и разделения версий.
- `tools/build_flat_2d_attempt.py` — сборка отдельных матовых вариантов.

Для пересборки нужен Python с Pillow и BeautifulSoup4: `python tools/build_asset_review.py`. При текущей сборке для подписей PNG используются шрифты Consolas из Windows. Для обычного просмотра Python не нужен.

Оригинальные изображения и описания Megabonk: [Megabonk.org](https://megabonk.org/database/items/). Они сохранены как референсы с индивидуальными ссылками на источники.
