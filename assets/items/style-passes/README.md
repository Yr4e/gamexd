# Предметы — семь прогонов

В исходной базе 85 уникальных предметов. Оригиналы и каталог находятся на уровень выше; исходные изображения сохранены без изменений.

1. pass-01.png — предметы 1–20, 5×4 ячейки.
2. pass-02.png — предметы 21–40, 5×4 ячейки.
3. pass-03.png — предметы 41–60, 5×4 ячейки.
4. pass-04.png — предметы 61–85, 5×5 ячеек.
5. pass-05.png — независимая переработка всех 85 оригиналов за один проход, не сборка из первых четырёх листов.
6. pass-06.png — уточнение детализации и читаемости пятого листа. Разрешение файла не увеличено: улучшение выполнено перерисовкой деталей.
7. pass-07.png — итоговое согласование шестого листа со стилем иконок оружия и дополнительная коррекция обводки.

Листы 5–7: 10 столбцов, восемь полных рядов и пять предметов слева в последнем ряду. Внешние свободные места не являются предметами. Фон чёрный, рамки простые серые, подписи и номера отсутствуют.

Результаты созданы встроенным imagegen. Промпты и последующие локальные корректировки сохранены в prompt-*.txt и correction-*.txt. Стилевой референс — assets/weapon-icons/icons_256/28_dawnhammer.png. Цвет обводки сверялся с конкретным исходным изображением; атрибут редкости сайта не использовался для автоматического перекрашивания. В первом листе исправлена жёлтая обводка Soul Harvester, в четвёртом — синяя обводка Ghost, в седьмом — синяя обводка Idle Juice.

Это семь листов для выбора художественного направления, с чёрной подложкой. Отдельные прозрачные PNG из этих новых листов ещё не нарезаны. Новые названия не назначались; связь с оригинальными именами сохранена в manifest.json и исходном каталоге.

preview.html — галерея сравнения. Первые три листа имеют размер 1402×1122, остальные — 1254×1254. Квадратными являются ячейки предметов; листы первых трёх групп имеют пропорции сетки 5×4.
