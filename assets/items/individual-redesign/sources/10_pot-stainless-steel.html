Pot (Stainless Steel) Megabonk Guide

🏺 LEGENDARY ITEM

Pot (Stainless Steel) is a Legendary item that raises weapon level caps. The first copy adds +10 weapon levels; unlock it by opening every chest and pot in Graveyard's first Crypt.

Effect: Increases WEAPON level cap only. First pot: +10 levels. Stacking has diminishing returns (-1 per additional pot, minimum +2).
📝 v1.0.49 Update

Changed in Christmas Patch: No longer affects Tomes. Use Wizard's Hat for Tome level caps instead.

🔓 How to Unlock Pot (Stainless Steel)

Unlocking Pot (Stainless Steel) requires opening every chest and pot in the first Crypt on Graveyard. Any character can complete it. The displayed timer may reach zero, but Spooky Steve gives you only a brief grace window to finish the route.

🏺 Step-by-Step Guide

  1. Start Graveyard: The achievement is tied to the first Crypt where the run begins; the later four-key Crypt is not the target.
  2. Plan the route: Scan side rooms immediately and leave the most direct exit path for last.
  3. Open everything: Break every pot and open every chest in that first Crypt.
  4. Use movement boosts: Monke, Birdo, Turbo Socks, and Agility Tome can make the collection route more forgiving.
  5. Use the grace window: Zero on the displayed timer is not an instant failure. Keep collecting until Spooky Steve appears; the achievement registers when the final required object is opened.
✅ Bandit Requirement Removed

Previous versions required the Bandit character for this unlock. This requirement has been removed in recent updates—any character can now complete the challenge.

💡 Pro Tips for Unlocking

🐰 Master Bunny Hopping

B-hopping significantly increases your movement speed. Practice this technique before attempting the challenge.

🗺️ Learn the Layouts

Crypt rooms have consistent layouts. Memorize common patterns to navigate faster.

🎮 Character Choice

Monke (wall climbing) or Birdo (double jump) can navigate awkward layouts more easily.

📦 E-Key Trick

Some pots and chests can be collected by jumping and pressing E without fully reaching them—saves valuable time.

🔧 Disable Other Items

Before starting, disable all tomes/items except movement boosters to increase their spawn rate.

🗺️ Use the Minimap

The minimap shows chest locations. Use it to ensure you don't miss any.

⚙️ Item Effect Breakdown

Weapon Level Cap (Diminishing Returns)

Pot (Stainless Steel) only affects weapons (not Tomes). The stacking mechanic works as follows:

  • 1st Pot: +10 weapon level cap
  • 2nd Pot: +9 weapon level cap
  • 3rd Pot: +8 weapon level cap
  • ... (continues decreasing by 1)
  • 9th+ Pot: +2 weapon level cap (minimum)

Need Tome Level Caps?

Use Wizard's Hat instead! This new item (added in v1.0.49) provides +5 Tome level cap, functioning like the old Pot effect for Tomes.

When is This Item Best?

  • Extended runs: The longer you play, the more value from extra weapon levels.
  • Weapon-focused builds: Pairs excellently with items that scale per weapon level.
  • Combine with Wizard's Hat: Get both weapon and tome level caps for maximum scaling.

❓ Frequently Asked Questions

How do you unlock Pot (Stainless Steel)?
Open every chest and pot in the first Crypt on Graveyard. Any character works, and the displayed timer can reach zero before the short Spooky Steve grace window ends.
Do I need Bandit to unlock this item?
No, the Bandit requirement was removed in a recent update. Any character with good movement can complete the challenge.
Do I need to escape the Crypt?
No. The achievement registers when every required chest and pot in the first Crypt has been opened. Reaching the exit is not part of the requirement.
Is Pot (Stainless Steel) worth the effort?
Yes, but with caveats. The first pot gives +10 weapon levels which is very powerful. However, stacking has diminishing returns. Consider combining with Wizard's Hat for tome levels too.
Does Pot (Stainless Steel) still affect Tomes?
No! Since v1.0.49 (Christmas Patch), it only affects weapons. Use Wizard's Hat for Tome level caps.
