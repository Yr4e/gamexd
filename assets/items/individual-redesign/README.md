# Индивидуальная переработка 85 предметов

Каждый номер связан с оригинальным каталогом Megabonk и своим цветом обводки. Источник эффектов: https://megabonk.org/database/items/. Значения в таблице отражают содержимое этого сайта, а не реализацию игрового баланса.

## Состав

- crops/ — 85 отдельных исходных вырезок из выбранного листа, без номеров и рамок.
- sources/ — сохранённые страницы отдельных предметов с описаниями эффектов.
- research.json — исходное название, эффект с сайта, ссылка и записанный под номером цвет обводки.
- plan.json — новые английские/русские названия, индивидуальные визуальные концепции, эффекты и промпты.
- prompts/ — 85 отдельных промптов. На каждый предмет выполняется собственный вызов встроенного imagegen с прозрачным фоном; исходная иконка не подаётся как референс формы. Референс оружия используется только для стиля.
- raw/ — отдельные сгенерированные оригиналы и записи об их создании.
- icons_256/ — итоговые прозрачные PNG 256×256; цветной контур и мягкое свечение добавлены кодом после генерации.
- catalog.csv и catalog.json — новая таблица соответствий с состоянием готовности и именами файлов.
- items-new-grid.png — лист новых готовых иконок с номерами, нанесёнными кодом.
- preview.html — галерея отдельных новых предметов.

## Обводка

Цвет задаётся по номеру и видимой обводке выбранного исходного листа. Он не вычисляется заново из поля rarity сайта, поскольку оно местами расходится с цветами оригинальных изображений.

- yellow: #FFD928
- pink: #FF239F
- blue: #1689FF
- mint: #55EDBB

Толщина цветного пиксельного контура — 3 пикселя на холсте 256×256; вокруг него добавлено слабое свечение. Рисунок вписывается с прозрачными полями, без обрезки и растягивания. Номера есть только на общем листе, сами PNG без текста и рамок.

## Воспроизводимость

- `python -X utf8 tools/prepare_individual_items.py` извлекает исходники и собирает описания. Это исследовательский этап; он не генерирует изображения.
- Индивидуальные изображения создаются встроенным imagegen по prompts/*.txt.
- `python tools/build_individual_items.py` обрабатывает имеющиеся raw/*.png, добавляет обводку, обновляет таблицу и сетку. Отсутствующие результаты помечаются pending, а не подменяются исходными иконками.

Эффект Golden Ring на исходном сайте отмечен как неподтверждённый. Для него не выдумывается численная механика; новый образ — условное «золотое обещание».

## Проверка готового набора

Все 85 номеров завершены. Проверены 85 отдельных записей о генерации, уникальность всех исходных и итоговых файлов, уникальность названий на обоих языках, RGBA 256×256, прозрачные поля и присутствие записанного цвета контура в каждом PNG. Результаты записаны в validation.json.

comparison.html показывает выбранный старый образ рядом с новым. Пользовательский ZIP содержит готовые PNG, исходные вырезки для сравнения, обе галереи, общий лист, таблицы, промпты и отчёт проверки. Большие raw-файлы и сохранённые веб-страницы остаются в проекте отдельно.
