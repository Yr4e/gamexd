# Megabonk — оригинальные предметы

Источник: https://megabonk.org/database/items/
Собрано 20 октября 2026 года. 85 карточек в порядке страницы: 22 Legendary, 12 Epic, 24 Rare, 27 Common.

- originals/ — 85 оригинальных файлов с сайта, без перерисовки и изменения байтов.
- items-grid.png — сетка 1440×1440, чёрный фон, простые серые квадратные рамки, без подписей и номеров. Изображения вписаны целиком с сохранением пропорций; увеличение выполнено nearest-neighbor.
- preview.html — локальная сетка оригинальных иконок без подписей.
- catalog.csv и catalog.json — идентификатор, оригинальное название, редкость, локальный файл, URL иконки и страницы, размер, формат, SHA-256. Новые названия пока не назначались.
- source-page.html — сохранённая страница, из которой извлечены данные; хранится для воспроизводимости, не используется как UI.

Порядок сетки: слева направо, сверху вниз, 10 столбцов. Последний ряд содержит 5 предметов.

Разрешение большинства оригиналов — 32×32; Bob's Light — 512×512, Turbo Skates — 86×88, Quin's Mask — 102×95. Встроенные в оригинальные изображения детали, обводки и подложки сохранены.

Повторная сборка: `python tools/collect_item_references.py`. Нужен Pillow. Уже скачанные файлы используются повторно; при ошибке загрузки сборка останавливается и не выдаёт неполный набор за полный.

Это оригинальные референсы Megabonk с указанного сайта. Авторство исходных изображений не заявляется; переработанные ассеты нашей игры будут создаваться отдельно.
