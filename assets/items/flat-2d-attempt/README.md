# Отдельная проба плоского 2D-стиля

Пять примеров из замечаний пользователя: 17, 20, 23, 27, 29. Это отдельный тест направления, не замена всех 85 иконок. В основном наборе на этом шаге исправляются только №1 и 2: целый цветной край и чёткая картинка восстановлены из версии before-outline-fix. Остальные 83 основных PNG проверяются по хешам.

Ориентир — оригинальные маленькие предметы Megabonk и наши более матовые №21, 22, 25, 26, 28. Предметы сохраняют свои новые названия, силуэт и смысл. Уменьшается объёмное освещение: без белых глянцевых пятен, сияющих центров, отражающих металлических рёбер, градиентного стекла и световых ореолов. Пена у пива остаётся белой как отдельный материал.

Каждая из пяти иконок отдельно отредактирована встроенным imagegen; входные изображения — соответствующий before/NN.png и style-references.png. Это редактирование, не CLI/API fallback. Промпты сохранены в prompts/NN.txt, исходники и сведения о генерации — raw/NN.png и raw/NN.json.

Код tools/build_flat_2d_attempt.py вписывает предмет целиком в 256×256, нормализует тело до 48 логических пикселей, ограничивает палитру до 16 цветов, увеличивает nearest-neighbor и добавляет один тонкий цветной край редкости. Новый тёмный разделительный контур не рисуется. Индивидуальные PNG прозрачные, без названий, номеров и рамок.

- preview.html — сравнение пяти вариантов в браузере, включая 64/32 px.
- flat-comparison.png — общий квадратный лист «сейчас / проба 2D / 64 px / 32 px» с текстом, нанесённым кодом.
- context-grid-85.png — тестовая сетка из 85 позиций, в которой заменены только пять выбранных иконок. Основные файлы от этого не меняются.
- icons_256/ — пять прозрачных PNG этой попытки.
- catalog.json — исходные и новые названия EN/RU, эффект, цвет редкости и путь каждого тестового PNG.
- before/ — пять неизменённых иконок для сравнения.
- validation.json — область теста, параметры и проверка сохранности основного набора.

Архив готовой попытки: output/items-flat-2d-attempt.zip. Большие raw-исходники доступны в проекте отдельно.
