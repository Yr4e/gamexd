# Отдельная матовая 2D-версия предметов

Актуальные десять номеров: 5, 6, 9, 12, 15, 17, 20, 23, 27, 29. Все PNG этой версии находятся отдельно от основного набора revision-simple/.

## Последние шесть правок

- №23 полностью создана заново по оригинальной лампочке Megabonk Bob's Light. Референс references/23-original.png. Старый кристалл сохранён в before-second-pass/. Магента-фон и декоративная рамка оригинала не переносятся на новую иконку.
- №5, 6, 9, 12, 15 отдельно переведены в тот же матовый 2D-стиль. Их размер тела 180 пикселей, на 6,25% меньше стандартных 192 пикселей этой версии. Пропорции сохранены, без обрезки.
- Ранее созданные №17, 20, 27 и 29 побайтово сохранены.
- Основные 85 PNG не меняются в этом проходе. Состояние проверяется по before-second-pass/baseline-main.json.

## Рисунок

Без глянцевых белых пятен, сияющих центров, отражающих металлических рёбер и градиентного стекла. Крупные цветовые участки, простое разделение материалов на тона. Пиксели и исходные цвета редкости сохранены. Каждая новая иконка создана/отредактирована отдельным вызовом встроенного imagegen. №23 — новая генерация по референсу; остальные пять — редактирование существующих предметов. Промпты находятся в prompts/NN.txt, полные исходники и сведения о генерации — raw/NN.png и raw/NN.json.

Сборка tools/build_flat_2d_attempt.py: 48 логических пикселей тела для стандартного размера, 45 для уменьшенного; 16 цветов тела, увеличение nearest-neighbor ×4, один внешний цветной край шириной 3 пикселя. Новый тёмный разделительный контур не добавляется. Итоговые 256×256 PNG прозрачные, без текста, номера и серой рамки.

## Файлы

- preview.html — все десять иконок рядом с исходными; ниже каждой показаны размеры 64/32 px.
- pass-02-comparison.png — квадратный лист последних шести правок; для №23 слева предыдущая 2D-проба с кристаллом.
- flat-comparison.png — квадратный лист всех десяти вариантов.
- context-grid-85.png — полная тестовая сетка, где десять позиций используют 2D-варианты. Основные PNG при этом не подменяются.
- icons_256/ — десять прозрачных PNG.
- catalog.json — номера, исходные и новые названия EN/RU, эффект, цвет редкости, размер и путь каждого тестового PNG.
- before/ — основные иконки для сравнения.
- approved-matte-style.png — референс утверждённого направления для последнего прохода.
- style-references.png и style-references-clean.png — первоначальные референсы оригиналов Megabonk и наших более матовых предметов.
- validation.json — проверка данных, области изменений и размеров.

Архив: output/items-flat-2d-attempt.zip. Большие raw-исходники доступны в проекте отдельно. Первый тест был выполнен на пяти предметах 17, 20, 23, 27, 29; одновременно в основном наборе были исправлены №1 и 2. В последнем проходе эти исправления и все остальные основные PNG сохранены.
