# Иконки оружия

30 отдельных PNG RGBA на прозрачном квадратном холсте 256×256.
Изображения вырезаны из source-sheet.png без генерации новых рисунков.
Серые рамки удалены. Вокруг рисунков оставлены прозрачные поля.
Рисунок перенесён в исходном пиксельном размере, без растягивания.

- icons_256/ — сами иконки, без рамок, подписей и фона.
- catalog.csv и catalog.json — оригинальные названия, новые английские и русские названия, пути к PNG.
- preview.html — просмотр на шахматной, светлой и тёмной подложках; шахматка не входит в PNG.
- preview-checker.png — общий контрольный лист с шахматной подложкой.
- source-sheet.png — исходный лист для воспроизводимого извлечения.

В исходнике прозрачность отсутствовала: мягкая альфа свечения восстановлена из изображения на чёрной подложке. Тёмные участки физических предметов сохранены отдельными масками; это не исходная авторская альфа.

Повторное извлечение: установить зависимости из tools/requirements-icons.txt и запустить `python tools/extract_weapon_icons.py` из корня проекта.

Исправления №7, 11 и 27 хранятся в revisions/ и автоматически заменяют вырезанные исходные версии при сборке. Они выполнены встроенным imagegen, промпты сохранены рядом. №7: отдельные стрела и тетива; №11: голубая аура с силуэтом; №27: две точки на правой грани центрального кубика. Для этих трёх иконок используется прозрачность сгенерированных PNG. Референс Aura: https://megabonk.org/images/database/weapons/Aura.png.

Порядок соответствует исходному листу: 6 столбцов, 5 строк, слева направо и сверху вниз. №21 — Verdict / Приговор, №28 — Dawnhammer / Рассветный молот, №29 — Voidgrasp / Хватка бездны.
