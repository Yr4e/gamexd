# GameXD · Иконки характеристик

Актуальный согласованный набор: **33 иконки, версия рисунков v11**. Прозрачные PNG 256 × 256.

[Открыть публичный предпросмотр](https://yr4e.github.io/gamexd/stat-icons/) · [Скачать PNG и каталог](stat-icons-33.zip) · [Вся сетка](preview-grid.png)

Каждая строка связывает номер, постоянный ID, русский и английский заголовки, ключ характеристики и файл. JSON и CSV содержат те же соответствия и SHA-256 файлов. Описания обозначают назначение характеристики без формул баланса. Ключи относятся к ассетам, не к полям игрового движка.
